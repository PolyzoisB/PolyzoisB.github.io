Software

Research code and computational tools.

This page is designed to make methodological work visible to both research collaborators and data-science employers. Link each project to a public repository when available.

SBI-ETAS

Simulation-based Bayesian inference framework for ETAS / ETASI models, aimed at inference under short-term catalog incompleteness and computationally challenging likelihoods.

PythonBayesian inferenceABC / SMC

Status: research code / publication workflow.

NN / SI Declustering

Automated nearest-neighbour declustering using a statistically identified threshold and Susceptibility Index diagnostics, validated on synthetic ETAS catalogs and real seismicity.

PythonClusteringETAS validation

Status: research software associated with the 2026 Earth and Space Science study.

ETAS calibration toolbox

Planned user-facing Python toolbox bringing together ETAS variants and multiple inference approaches such as stochastic declustering, EM-type methods, gradient-based optimisation and simulation-based inference.

PythonETASInference

Status: planned project.

Other computational work

Seismicity simulation & optimisation

Implementation of earthquake point-process simulation and inversion workflows in Python and Fortran, including stochastic optimisation and catalogue-based diagnostics.

Machine-learning pipelines

TensorFlow / Keras and scikit-learn workflows for autoencoders, one-class SVMs, novelty detection and federated-learning experiments using FLOWER.
